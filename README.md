🏎️ Mechatronics Blueprint: Automated Manual Transmission (AMT)

One of my most ambitious conceptual projects is designing an Automated Manual Transmission (AMT) system for combustion engines (based on the Tiger engine platform). This project integrates control logic, sensory feedback, and mechanical actuation.

"This project proves I understand systems from the bit/byte level all the way up to physical actuators. While I currently lack the capital to build the physical Lamborghini replica, the entire control architecture and logic has been thoroughly mapped out."

⚙️ Technical Design Specifications

| Component | Specification | Function in System |
| :--- | :--- | :--- |
| Primary Actuator | 3x Solenoid Valves (5/3 Ways) | Controls air/pressure flow to engage the clutch fork and select gears. |
| Feedback Sensor | Magnetic Sensors (Hall Effect) | Detects actual gear position and clutch engagement/disengagement status in real-time. |
| Control Unit (Logic) | Microcontroller (ATMega/STM32 - Conceptual) | Receives sensor inputs, runs state-machine algorithms, and sends PWM/ON-OFF signals to solenoids. |
| Controlled Object | Manual Gearbox (Tiger Engine) | Mechanical transmission converted from manual (foot) operation to electronic (automated) control. |

📊 Designed Control Logic (State Machine)

​🟢 Neutral (N): All solenoids off, clutch disengaged.
​🟡 Start / 1st Gear: Solenoid A activates, pressing the clutch. Sensors verify engagement, then clutch releases gradually.
​🔴 Gear Shifting (Up / Down):
​Solenoids B & C alternate to pull/push the gear selector fork.
​Magnetic sensors confirm successful gear engagement before the clutch re-engages.
